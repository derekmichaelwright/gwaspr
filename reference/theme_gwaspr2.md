# theme_gwaspr2.

ggplot theme.

## Usage

``` r
theme_gwaspr2(
  x,
  bgFill = "grey95",
  lineColor = "white",
  lineSize = 0.75,
  stripFill = "white",
  caption.adj = 1,
  caption.size = 7,
  ...
)
```

## Arguments

- x:

  ggplot

- bgFill:

  background fill color

- lineColor:

  color of axis lines

- lineSize:

  border line size

- stripFill:

  strip background color

- caption.adj:

  hjust for the caption

- caption.size:

  size of the caption

## Value

ggplot with gwaspr theme
