# gg_LD_Decay

Creates a number of LD decay plots.

## Usage

``` r
gg_LD_Decay(xG = myG, outputFolder, markerNum = 200)
```

## Arguments

- xG:

  GWAS genotype object. Note: needs to be in hapmap format.

- outputFolder:

  Folder to place RData files into.

- markerNum:

  Number of markers to randomly select for each chromosome.

## Value

LD decay plots.
