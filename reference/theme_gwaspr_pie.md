# theme_gwaspr_pie.

ggplot theme.

## Usage

``` r
theme_gwaspr_pie(
  x,
  bgFill = "white",
  lineSize = 0.75,
  stripFill = "white",
  caption.adj = 1,
  caption.size = 7,
  ...
)
```

## Arguments

- x:

  ggplot

- bgFill:

  background fill color

- lineSize:

  border line size

- stripFill:

  strip background color

- caption.adj:

  hjust for the caption

- caption.size:

  size of the caption

## Value

ggplot with agData theme for pie graphs
