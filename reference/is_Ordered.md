# is_Ordered

Create a table of which GWAS results files are ordered by p.value.

## Usage

``` r
is_Ordered(folder = "GWAS_Results/", nrows = 10000)
```

## Arguments

- folder:

  Folder containing GWAS results.

- nrows:

  Number of rows to read.

## Value

A table of which models have been run on each trait.
