
# gwaspr <img src="man/figures/logo_gwaspr.png" align="right" width="90" height="100" />

`gwaspr`: an `R` package for plotting GWAS results from the `GAPIT`
package

------------------------------------------------------------------------

# Instal gwaspr

``` r
devtools::install_github("derekmichaelwright/gwaspr")
```

``` r
library(gwaspr)
```
